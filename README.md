# Tracker

Allows tracking of events in a web interface with basically zero overhead.
Most other tools require more than one click, e.g. "enter event", "select event", "confirm".
This tool is optimized to allow you to just press a button and be done.
The tool also allows you to define different access codes which have different permissions, e.g. to allow to enter tracking data from less-trusted devices, but not allow viewing of the history with the same credentials.
